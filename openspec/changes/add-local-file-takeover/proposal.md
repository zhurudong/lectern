## Why

用户在浏览器打开本地 Markdown、SQL、Java 等文件后仍需回到 Lectern 再选一次文件。按用户配置自动接管本地文件地址，消除重复选择，复用已有阅读能力。

## What Changes

- 在当前标签页接管匹配的 `file://` 文件，进入单文件阅读模式。
- 增加自动打开设置：总开关、与预览格式表同源的后缀多选、全选、清空、恢复默认；HTML 和图片默认不选。
- 展示 Chrome 文件网址授权状态及设置入口；未授权时仍可使用原生文件选择器。
- **BREAKING**：将零权限/禁止所有读取 API 符号的旧约束改为明确限定本地文件访问的权限和读取入口；保留不访问 HTTP(S)、不外传内容、只读约束，更新规格、文档与构建门禁。

## Capabilities

### New Capabilities

- `local-file-takeover`: 本地地址匹配、配置、授权引导、自动打开与失败恢复。

### Modified Capabilities

- `project-access`: 增加本地 URL 单文件入口，明确选择器与自动接管不同的授权方式，以及新的权限验证契约。

## Impact

影响扩展后台、manifest、类型表、单文件状态和符号 Worker、设置界面、构建门禁及中英文文档。不接管 HTTP(S)、网页子资源、下载历史、目录或系统默认应用关联；不自动获得父目录句柄。
