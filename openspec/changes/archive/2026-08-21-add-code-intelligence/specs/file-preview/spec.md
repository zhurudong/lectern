## ADDED Requirements

### Requirement: 按行定位与高亮

预览区 SHALL 支持按行定位:打开文件时若指定了目标行,SHALL 将该行滚动到可见区域(尽量居中)并施加短暂的行高亮标识,便于用户在跳转后立刻找到落点。该通道 SHALL 被所有导航入口共用(跳转到定义、查找引用、文件大纲、全局符号搜索、全文搜索结果、导航栈前进/后退)。

该要求 SHALL 以**不变量**方式成立,不按渲染通道切分:

> **凡指定了目标行,当前渲染通道 MUST 把该行对应的内容定位到可见区域并短暂标识。** 若该通道没有"行"的概念(如 Markdown 富文本渲染视图),SHALL 定位到**该源码行所对应的渲染元素**(如该行的标题、段落),MUST NOT 因为"渲染视图没有行"而静默不动作。

在**当前已打开文件内**定位到某行时,SHALL 直接滚动定位,不要求重新读取文件内容;跨文件跳转仍按既有约定从磁盘重新读取目标文件。目标行号超出文件实际行数,或文件因大文件降级被截断而目标行落在截断范围之外时,SHALL 定位到可定位的最近位置并给出明确提示,MUST NOT 报错、白屏或使预览区失去内容。

#### Scenario: 跨文件跳转定位到指定行

- **WHEN** 用户从符号搜索结果中选择 `handler.go:42`
- **THEN** 预览区打开 `handler.go`,第 42 行滚动到可见区域并短暂高亮

#### Scenario: 当前文件内定位不重读文件

- **WHEN** 用户在当前文件的大纲中点击某个函数
- **THEN** 预览区滚动到该函数定义行并短暂高亮,不重新读取该文件、不出现内容闪烁

#### Scenario: Markdown 富文本视图中的行定位

- **WHEN** 用户在 Markdown 富文本(渲染)视图下,从大纲中点击某个标题
- **THEN** 渲染视图滚动到该标题对应的渲染元素并短暂标识,**停留在富文本视图**,MUST NOT 静默无反应,也 MUST NOT 为了定位而强制切换到源码视图

#### Scenario: 目标行超出可定位范围

- **WHEN** 目标行号大于文件实际行数,或该行落在被截断文件的未加载部分
- **THEN** 预览区定位到最近的可定位位置并提示目标行不可定位,文件内容照常展示

## MODIFIED Requirements

### Requirement: 大文件降级

超过阈值(默认 5 MB)的文本文件 SHALL 走降级渲染:仅加载文件开头部分(默认前 1 MB)并明确提示"文件过大,已截断展示";降级过程 MUST NOT 阻塞界面。被截断展示的文件 SHALL 同时明示其代码理解覆盖范围受限(符号未被索引,或仅覆盖已加载部分),MUST NOT 让用户以为大纲与跳转覆盖了整份文件。

#### Scenario: 超大日志文件

- **WHEN** 用户点击一个 50 MB 的 `.log` 文件
- **THEN** 预览区在短时间内展示文件开头内容与截断提示,界面全程可交互

#### Scenario: 截断文件的代码理解范围明示

- **WHEN** 用户点击一个 50 MB 的 `.c` 文件
- **THEN** 预览区在截断提示之外明示该文件的符号索引覆盖受限,大纲区给出对应说明
