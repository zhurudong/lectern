## 1. 焦点与可访问性骨架

- [x] 1.1 目录树容器加 `role="tree"` + `tabIndex={0}`,行加 `role="treeitem"` + 稳定 `id`,目录行加 `aria-expanded`,并给出层级语义(`aria-level`)(`role=tree` + `tabIndex=0` 容器;行 `role=treeitem` + `aria-level`,目录另加 `aria-expanded`;行 id 由路径派生 `cv-row-${encodeURIComponent(path)}`,无空白字符可直接作 HTML id)
- [x] 1.2 活动行状态用**路径 `string[]`** 保存(不是行索引、不是 DOM 引用),容器用 `aria-activedescendant` 指向当前活动行的 `id`(活动行存 `string[]` 路径;容器 `aria-activedescendant` 指向该行 id)
- [x] 1.3 活动行标识样式(焦点环),**与选中态视觉可区分**,浅色/暗色各定一组值(活动行 = 内嵌焦点环 `--focus-ring`,选中行 = 背景填充 —— **两种不同视觉手段**,可同时出现在不同行;两主题各定一组值。环只在 `.tree:focus` 时显示,避免留下看起来像选中的陈旧标记)
- [x] 1.4 容器获得焦点时若尚无活动行,默认落在首行(或当前选中文件所在行)(无活动行时优先落在当前预览的文件所在行,否则首行)

## 2. 键位行为(WAI-ARIA tree 模式)

- [x] 2.1 `↑` / `↓`:在 `visibleRows()` 结果的相邻行间移动活动行;`Home` / `End` 移到首 / 末行
- [x] 2.2 `→`:目录未展开 → 展开(复用 `toggleDir`);已展开 → 移到第一个子项;文件 → 无操作
- [x] 2.3 `←`:目录已展开 → 折叠;目录已折叠或文件 → 活动路径 `slice(0,-1)` 回父目录(**不需要父指针**)
- [x] 2.4 `Enter`:文件 → 走**既有 `onRowClick` 同一条通道**打开预览;目录 → `toggleDir`(文件走 `onRowClick`、目录走 `toggleDir`,**与鼠标同一条通道**)
- [x] 2.5 **MUST NOT 为键盘另写一套打开文件/展开目录的实现** —— 入口是机制,行为是契约,只有一份(全文件搜索确认:键盘分支里没有任何独立的打开/展开实现)
- [x] 2.6 处理器挂在**容器**上而非 window;确认搜索框聚焦时事件根本不进树(用焦点归属天然分流,不写条件判断防御)(处理器挂容器;E2E 实测 ⌘K 聚焦搜索框后连按 3 次 ↓,活动行 id 前后不变 —— 焦点归属天然分流,没写任何"判断焦点在别处"的条件)
