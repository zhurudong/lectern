# project-access Specification

## Purpose

负责选择器、拖放和本地文件网址的打开入口，以及项目句柄持久化、最近项目重连与授权续期。选择器和拖放无需文件网址设置，自动接管需要用户开启 Chrome 文件网址访问。
## Requirements
### Requirement: 打开本地目录

用户 SHALL 能通过系统原生目录选择对话框打开一个本地目录作为项目；打开成功后进入查看器界面。目录选择器入口 MUST NOT 要求用户开启“允许访问文件网址”等浏览器设置；该设置仅为可选的本地 URL 自动打开功能所需。

#### Scenario: 首次打开目录
- **WHEN** 用户在查看器页面点击“打开文件夹”并在系统对话框中选择一个目录
- **THEN** 查看器展示目录树，右侧为空预览区，无需文件网址权限

#### Scenario: 用户取消选择
- **WHEN** 用户在系统目录选择对话框中点击取消
- **THEN** 查看器不报错、不改变已有状态

### Requirement: 打开单个本地文件

用户 SHALL 能通过系统原生文件选择对话框打开单个本地文件,直接进入该文件的预览。

#### Scenario: 打开单文件

- **WHEN** 用户点击"打开文件"并选择一个文件(如 `main.go`)
- **THEN** 查看器直接在预览区渲染该文件,目录树区域不展示项目树

### Requirement: 拖放打开本地目录或文件

用户 SHALL 能将一个本地目录或文件拖到查看器页面任意位置打开,包括首页、目录树、代码预览区和 Git 视图。目录 SHALL 进入项目浏览并计入最近项目;文件 SHALL 直接进入单文件预览且不计入最近项目。拖放期间 SHALL 显示提示,离开页面、取消或放下后 SHALL 清除提示。

#### Scenario: 拖入目录或文件

- **WHEN** 用户将一个本地目录或文件拖入查看器页面并松开
- **THEN** 扩展阻止浏览器默认的文件导航,直接使用拖放授予的句柄打开,无需再次选择文件或开启文件网址访问

#### Scenario: 无法打开或拖入多项

- **WHEN** 用户一次拖入多个目录/文件,或浏览器无法提供可读的拖放句柄
- **THEN** 页面显示可关闭的错误提示,保留已有项目和预览,不静默选择其中一项

#### Scenario: 后续操作优先

- **WHEN** 拖放打开尚未完成,用户又发起打开、进入其他项目或单文件模式、或回到首页
- **THEN** 先前请求的异步结果不覆盖后续操作

#### Scenario: 普通文本拖放

- **WHEN** 用户拖动普通文本或网页链接
- **THEN** 文件拖放入口不拦截事件,不触发打开或文件错误提示

### Requirement: 最近项目持久化与重连

扩展 SHALL 将已打开的目录句柄持久化保存,并在入口界面展示"最近项目"列表(至少保留最近 10 个,按最近打开时间排序)。选择最近项目时 SHALL 复用已保存的句柄重连,如浏览器要求重新授权则引导用户完成授权。最近项目列表仅记录目录;以"打开文件"方式打开的单个文件 MUST NOT 计入最近项目列表。

#### Scenario: 一键重开最近项目

- **WHEN** 用户重启浏览器后打开查看器,并点击最近项目列表中的某一项
- **THEN** 若权限仍有效(或用户在授权提示中确认),查看器直接进入该项目的浏览界面

#### Scenario: 单文件不进入最近项目

- **WHEN** 用户通过"打开文件"打开单个文件后回到入口界面
- **THEN** 最近项目列表不包含该文件条目

#### Scenario: 句柄失效降级

- **WHEN** 用户点击的最近项目对应目录已被删除、移动,或用户拒绝重新授权
- **THEN** 查看器提示该项目不可用并提供"从列表移除"选项,不崩溃、不进入空白状态

### Requirement: 权限边界

扩展 MUST 仅访问用户通过选择器或 Chrome 文件网址开关授权的本地文件，MUST NOT 将文件内容或路径发送到远程服务。本地 URL 入口 MUST 验证协议和本机地址，拒绝 HTTP(S) 与远程文件主机，禁止跟随重定向；文件来源不得由渲染内容触发任意读取。

发布产物 MUST 保持只读：不得引用文件写入 API `createWritable`、`showSaveFilePicker`、`removeEntry`。权限和 CSP SHALL 由构建门禁按准确允许列表验证，只允许本地接管所需能力和 `file:///*` 主机范围，不允许网页注入或远程主机权限。纯阅读版本的连接 CSP MUST 仅允许扩展自身资源与本地文件。

网络 API 检查 SHALL 只允许一个经独立审计、限制本地文件协议的读取模块；其余模块的网络 API 引用 MUST 失败。该模块的精确产物内容 SHALL 受到门禁验证，且 MUST 有 HTTP(S)/远程文件主机/无效地址的负向验证。更新 README、安全说明与门禁说明，使其描述实际能力，而非继续宣称零权限或完全不存在读取 API。

门禁 SHALL 检查发布产物而非验收脚本。自动化 MUST 从当前源码构建再验证；人工检查发现产物早于源码时 MUST 将过期提示与结论放在同一处。工具链意外注入的网络 API 仍 MUST 失败；降低最低 Chrome 版本时 MUST 重新评估已禁用的兼容兜底。

#### Scenario: 无网络传输
- **WHEN** 用户自动打开或手动浏览本地文件
- **THEN** 不发起 HTTP(S) 请求，不将内容和路径外传

#### Scenario: 非本地地址拒绝
- **WHEN** 自动打开入口收到 HTTP(S)、远程 file 主机或畸形 URL
- **THEN** 读取前拒绝地址并显示错误

#### Scenario: 权限声明可被产物检查自证
- **WHEN** 发布产物新增未允许的权限、主机、注入脚本、传输符号或修改受审计读取模块
- **THEN** 构建门禁失败并指明原因

#### Scenario: 零网络可被产物检查自证
- **WHEN** 运行发布产物的网络能力检查
- **THEN** 仅独立且摘要匹配的本地文件读取模块可以含读取 API，其他脚本出现网络 API 符号均失败，连接 CSP 不允许远程服务

#### Scenario: 只读可被产物检查自证
- **WHEN** 发布产物包含文件写入 API 符号
- **THEN** 门禁失败；验收脚本构造夹具的写入不属于发布产物

#### Scenario: 产物早于源码时不得沉默通过
- **WHEN** 跳过构建并检查早于源码的产物
- **THEN** 门禁结论同时包含过期提示

#### Scenario: 检查对象是发布产物而非仓库
- **WHEN** 验收脚本为构造夹具而使用文件写入 API
- **THEN** 该操作不违反只读约束，门禁仅针对发布产物
