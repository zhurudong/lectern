# localization Specification

## Purpose
为界面文案提供不依赖第三方库的多语言机制:语言选择与持久化、按 key 取词与占位符插值、缺键回退、切换即时生效,并约束字体栈不随语言改变。本次仅落地机制与一个样板面板,其余文案的批量迁移不在范围内。
## Requirements
### Requirement: 界面语言可选择、持久化、即时切换

查看器 SHALL 提供中文与英文两种界面语言,并提供一个**不依赖键盘快捷键**的界面入口(顶栏语言开关)在两者间切换。切换 SHALL 即时生效:已接入 i18n 的界面文案 MUST 立即以新语言重渲染,无需刷新。所选语言 SHALL 持久化(localStorage),重载后保持。

默认语言 SHALL 由单一裁定点决定:已存储的选择优先;无存储时按配置决定是否依据浏览器语言(`navigator.language`)选择,否则回落到中文。

#### Scenario: 切换语言即时重渲染

- **WHEN** 用户在顶栏点击语言开关
- **THEN** 已接入 i18n 的面板(如入口页)立即以另一种语言显示,无需刷新页面

#### Scenario: 语言选择持久化

- **WHEN** 用户选择英文后重载页面
- **THEN** 界面以英文加载(该选择从 localStorage 恢复)

### Requirement: 按 key 取词、占位符插值与缺键回退

界面文案 SHALL 经由 `t(key, params?)` 取自按语言分组的翻译表,MUST NOT 在组件里写死可见文案。`t()` SHALL 支持 `{name}` 形式的占位符插值(用于相对时间、进度计数等动态串)。

取词 SHALL 遵循三级回退:当前语言 → 中文 → key 本身。因此在批量迁移期,英文表只覆盖部分 key 时,未覆盖处 MUST 显示中文原文而非空白或报错,使逐面板迁移成为安全的增量过程。

#### Scenario: 动态串占位符插值

- **WHEN** 入口页展示"最近项目"的相对打开时间
- **THEN** 文案由带占位符的模板插值得到(如 `{n} 分钟前` / `{n} min ago`),数值正确填入

#### Scenario: 英文缺键回退中文

- **WHEN** 某文案的 key 尚未提供英文翻译,而界面语言为英文
- **THEN** 该处显示中文原文(不显示空白、不抛错)

### Requirement: 语言切换不改变字体栈

界面语言切换 MUST NOT 改变 CSS 字体声明。中英文共用同一字体栈(对拉丁与 CJK 均有合理回退),语言切换只改变文案与 `<html lang>` 属性,MUST NOT 触发字体重排或布局抖动。

#### Scenario: 切换语言字体不变

- **WHEN** 用户在中英之间切换界面语言
- **THEN** 页面字体栈保持不变,仅文案与 `<html lang>` 改变
