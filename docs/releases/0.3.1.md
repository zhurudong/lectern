# Lectern 0.3.1

This is the first source-backed public release of Lectern. It replaces the
initial Chrome Web Store 0.3.0 package, which was cut before the final
navigation verification completed.

## Fixed

- Keyboard navigation now lands the caret on the target symbol or result
  column, not merely on the target line's viewport position.
- Back/forward navigation restores the meaningful caret line when one exists.
- Closing search and candidate overlays hands focus to the intended reading
  surface, so the next keyboard action continues from the result.
- Symbol, file-name, outline, reference and full-text entry points share the
  same verified focus/caret handoff behavior.

## Artifacts

- `lectern-0.3.1.zip`: unzip and load the enclosed `lectern/` directory from
  `chrome://extensions`.
- `lectern-0.3.1-web-store.zip`: the exact root-manifest package submitted to
  the Chrome Web Store.
- Each archive has a corresponding `.sha256` file.

Both archives are plain outputs of the same clean build. They are not
obfuscated. Before publication the build passed the zero-network, read-only,
permission, language-coverage and TypeScript gates.

To verify from source instead of trusting an archive:

```bash
npm ci
npm run build
npm run check
```

Known non-blocking investigations remain documented in OpenSpec: an
intermittent Dockerfile highlighting assertion and an intermittent default-row
focus assertion under full-suite load.
