# Lectern 0.3.4

This release adds side-by-side comparison of any two files in a project, an
English interface, and navigable-language support for Rust and PHP. Lectern
still has no network access, requests no extension permissions, and performs no
write of any kind.

## Added

- **Compare any two files.** From a text file's preview, pick another file in
  the project and view the two side by side with per-side syntax highlighting.
  This coexists with 0.3.3's Git Changes view without conflict: both compare
  surfaces share one set of diff-navigation keys (⌥↑ / ⌥↓ for previous / next
  difference), grouped under a single **Compare** section in the keyboard help.
- **English UI.** The entire interface is translated; a top-bar switch toggles
  between 中文 and English and re-renders instantly. The default now follows the
  browser: `zh-*` browsers start in Chinese, everything else starts in English.
  An explicit choice is remembered per browser and always wins over detection.
- **Rust and PHP** join the navigable languages (outline, jump-to-definition,
  find-references), bringing the total to nine. Languages without a first-class
  grammar keep honest "highlight-only" labelling rather than pretending to
  support navigation.

## Boundaries kept honest

- File comparison is read-only on both sides (no accept / revert / merge
  controls) and selects its target from within the already-authorized project —
  it never opens a system file picker or requests a new grant.
- Oversized or truncated comparisons, and approximate diffs that exceed the work
  budget, say so in the view instead of silently presenting a partial or
  inflated result.
- The English tables fall back to Chinese then to the key, so a missing string
  can never render blank; key parity is checked (308 keys per language).
- AI explanation is intentionally not part of this release.

## Fixed

- Repaired two pre-existing end-to-end test-harness defects inherited from 0.3.3
  (a deterministic timeout in the large-directory virtual-scroll test and a
  dev-only fixture tripping the read-only invariant scan) so the suite runs to
  completion again. The shipped `dist/` read-only guarantee is unchanged; the
  invariant scanner now narrowly exempts the dev-only Git fixture while asserting
  it never reaches a production build.

## Artifacts

- `lectern-0.3.4.zip`: unzip and load the enclosed `lectern/` directory from
  `chrome://extensions`.
- `lectern-0.3.4-web-store.zip`: the root-manifest package for the Chrome Web
  Store.
- Each archive has a corresponding `.sha256` file.

Both archives are plain outputs of the same clean CI build. Before publication,
the source passed TypeScript/build checks, zero-network/read-only/permission
invariants, language coverage reconciliation, symbol-extraction accuracy checks,
Git object/ref/graph/worktree/service tests, UI contract negative controls, and
the full end-to-end suite in both Chinese and English.

To verify from source:

```bash
npm ci
npm run build
npm run check
```
