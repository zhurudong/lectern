# Lectern 0.3.5

This patch keeps Git review context stable while moving between the Files and Changes views.

## Fixed

- Files and Changes now share one persisted, resizable sidebar width, so switching views no longer changes the left pane geometry.
- The Changes file list can be resized with the same divider behavior as the Files tree.
- A Git comparison remains mounted for the current project, preserving selected refs, comparison mode, changed file, loaded diff and reading position across temporary view switches.
- Switching views no longer probes the repository or recomputes the comparison.
- A localized **Recompare** action explicitly reloads the current local repository and worktree while retaining the selected endpoints and mode.
- Changing projects or leaving project mode releases the retained Git worker and session.

## Invariants

- The extension remains read-only, offline and permission-free.
- Git comparisons still use only local refs, objects and worktree files.
- File comparison and the Chinese/English interface introduced in 0.3.4 remain unchanged.

## Artifacts

The tag-driven release workflow publishes both a complete release archive and a Chrome Web Store archive. Upload `lectern-0.3.5-web-store.zip` to the store.
