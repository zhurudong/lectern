# Lectern 0.4.0 — release candidate

This candidate integrates the current reader baseline with optional native AI terminals, SQL outline support and configurable opening of local file URLs. Existing English/Chinese UI, Rust/PHP navigation and file comparison are preserved.

- Standard build: local, read-only reader; no native terminal permission.
- AI candidate: resizable terminal beside the reader, persisted project association, English/Chinese setup and error guidance. Requires macOS 13.5+, Google Chrome, a separate matching Lectern Companion and an installed/authenticated AI CLI.
- CLI commands may modify files and communicate with their model provider. See the updated privacy policies for the extension, companion and CLI boundaries.
- Localized extension metadata, bundled license notices and automated release checks are included. Vite is updated to 6.4.3.

The [companion 0.2.1 unsigned preview](https://github.com/zhurudong/lectern/releases/tag/companion-v0.2.1) is publicly available for Apple silicon and Intel Macs; macOS may block installation or launch. Anonymous downloads and checksums have been verified, and the [privacy policy](https://github.com/zhurudong/lectern/blob/companion-v0.2.1/PRIVACY.md) is public. The user confirmed extension ID `ahmcjpgaejjfgiihipkjlhmepcnkbddm` and that version 0.4.0 can be uploaded; no highest previous version is assumed.

This is not a published extension release. Clean installation on supported architectures and the manual store submission remain outstanding. CI creates draft releases only; the AI ZIP remains a candidate until installation verification is recorded.
