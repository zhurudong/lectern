# Lectern 0.4.1

The optional AI terminal now fits into the reader with a compact toolbar and a choice of right or bottom docking.

- Move the terminal beside or below the code, keeping the file tree full height. Placement, width and height are remembered independently.
- Resize by dragging or with the keyboard. The reader retains usable space as the window shrinks.
- Keep the same session and output when changing docking position, theme, language or file/Git view.
- Use the toolbar arrow to reconnect. CLI settings, project association and installation help are available through the settings button.
- Follow the reader's light or dark theme. Fix delayed project-tab focus restoration stealing focus from a loading tree.

The AI build still requires macOS 13.5+, Google Chrome, the separate [Companion 0.2.1 unsigned preview](https://github.com/zhurudong/lectern/releases/tag/companion-v0.2.1), and an installed/authenticated AI CLI. The companion and extension permissions are unchanged. Existing Companion 0.2.1 installations need no update for this release. Closing the terminal or reconnecting starts a new session; docking alone does not.

The pure reader build remains local and read-only without Native Messaging. The optional CLI runs with the user's permissions and its own model-provider settings; it can modify files and transmit context to that provider.

The implementation passed all 387 reader browser scenarios, the loading-tree focus regression, pure-build checks, AI browser scenarios and Linux/macOS CI. Those AI browser scenarios use an isolated mock native host and do not call a model. Historical manual installation testing covers the unchanged companion on ARM64 as an upgrade with a real CLI request. Clean macOS, Intel runtime and store-installed validation remain outstanding.
