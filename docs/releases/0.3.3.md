# Lectern 0.3.3

This release adds local, read-only Git snapshot comparison. Lectern still has
no network access, requests no extension permissions, and exposes no Git write
operation.

## Added

- A project-level **Files / Changes** switch. The Changes view lists modified,
  added and deleted paths and opens each path in a read-only unified diff.
- Comparison endpoints for the current worktree, local branches,
  remote-tracking refs, tags, and full or uniquely abbreviated commit IDs.
  Remote-tracking refs are explicitly labelled as local snapshots; Lectern
  never fetches them.
- **Review changes** mode compares the merge base with the target. **Direct
  comparison** compares the two selected endpoints exactly.
- Lazy Git object reading for loose objects and pack v2 files, including OFS
  and REF deltas, bounded reads, bounded caches, and on-demand blob loading.
- Explicit metadata views for binary, oversized, gitlink, mode-only and
  unsupported repository states.

## Safety and boundaries

- Git access is local and read-only: no fetch, pull, checkout, index, stage,
  commit, merge, ref update, lock file, or filesystem write.
- Supported repositories are SHA-1, non-bare repositories whose object database
  remains inside the directory authorized by the user. SHA-256 repositories,
  bare repositories, and authorization-external gitdirs or alternates report a
  specific unsupported reason.
- Worktree comparisons disclose the browser's executable-bit, symlink, and
  global-ignore visibility limits instead of claiming complete equivalence.
- AI explanation is intentionally not part of this release.

## Artifacts

- `lectern-0.3.3.zip`: unzip and load the enclosed `lectern/` directory from
  `chrome://extensions`.
- `lectern-0.3.3-web-store.zip`: the root-manifest package for the Chrome Web
  Store.
- Each archive has a corresponding `.sha256` file.

Both archives are plain outputs of the same clean CI build. Before publication,
the source passed TypeScript/build checks, zero-network/read-only/permission
invariants, language coverage reconciliation, Git object/ref/graph/worktree/
service tests, and UI contract negative controls.

To verify from source:

```bash
npm ci
npm run build
npm run check
```
