Lectern，把 Chrome 变成本地代码阅读工作台。

打开本机项目，浏览源码、跳转定义、搜索符号、查看改动，也可以在代码旁使用自己的 AI CLI。支持 29 类语言／语法高亮，还能在浏览器打开指定后缀的本地文件时自动渲染。适合熟悉陌生项目、阅读开源代码和审查本地改动。

1. 直接读取本地项目
选择文件夹即可浏览目录树，也可单独打开文件，无需先上传项目或启动 IDE。阅读器在本机只读处理文件；代码、文档、配置和图片可以在同一界面查看。未安装 AI 伴随程序也能使用阅读功能。

2. 在代码旁使用本机 AI 终端（macOS 预览）
在阅读区右侧打开可选终端，连接已安装的 Codex、Claude Code 等本机 AI CLI，边读代码边提问。终端嵌入当前页面，不另开终端窗口；拖动分隔线即可调整宽度。每个项目首次在系统选择器中关联一次本机目录，后续自动复用。沿用自己的 CLI 登录和模型配置，无需另建 Lectern 账号。

3. 29 类语言／语法高亮，配合大纲与代码导航
27 类提供专用高亮：Python、Java、C、C++、Go、JavaScript（含 JSX）、TypeScript（含 TSX）、Rust、PHP、Markdown、SQL、JSON、YAML、TOML、XML、HTML、CSS、SCSS、Sass、Less、Shell、Ruby、Kotlin、C#、Groovy、Dockerfile、CMake。
Vue 和 Svelte 提供近似高亮，并在界面明确标注。
其中 Python、Java、C、C++、Go、JavaScript、TypeScript、Rust、PHP 共 9 类支持文件大纲、跳转到定义、查找引用和项目符号搜索；Markdown 和 SQL 也提供文件内大纲。还可按文件名或全文搜索项目，并沿导航历史回到之前的位置。定义与引用查找基于语法和符号名匹配，不保证与语言服务器同等精确。

4. 打开指定后缀，自动进入阅读视图
在“自动打开”中选择后缀，并开启 Chrome 的“允许访问文件网址”后，在浏览器打开 .md、.sql、.java、.py 等匹配的本地文件，即可在当前标签页自动进入 Lectern 的对应预览。可从 72 种支持的后缀中选择，涵盖代码、Markdown、纯文本和图片，随时调整或关闭。该功能仅适用于 file:// 本地文件地址。

5. 阅读 Markdown、配置与图片
Markdown 支持富文本与源码视图切换、标题大纲、表格及代码块高亮。打开项目文件夹后，可查看文档中的本地相对路径图片，并跳转项目内链接。PNG、JPEG、GIF、SVG、WebP 等图片可直接预览，日志和常见配置文件也可阅读。

6. 对比文件，审查本地 Git 改动
并排比较两个文件，查看差异；也可选择本地 Git 分支、Tag、提交或当前工作区，查看新增、修改和删除的文件。支持从共同祖先审查改动，或直接比较两个版本。Git 视图读取本机快照，不自动拉取远端仓库。

7. 按自己的习惯阅读
支持中英文界面、浅色与暗色主题、可调整的分栏、可折叠的大纲，以及目录树和代码导航的键盘操作。

AI 终端的安装与使用
终端目前提供 macOS 13.5 及以上版本的预览功能，需要 Google Chrome、单独安装 Lectern Companion，以及已安装并登录的 AI CLI。Codex 和 Claude Code 可直接选择；其他 CLI 可尝试配置可执行文件的绝对路径，兼容性取决于该 CLI。伴随程序包含运行环境，无需为它另外安装 Node.js。关闭终端会结束当前 CLI 会话，重新打开会启动新会话。
Lectern Companion 从 GitHub Releases 下载，目前未签名、未公证。macOS 可能阻止安装或启动，需要用户核对来源后决定是否允许；受管理的 Mac 可能限制安装。

本地阅读与 AI 数据边界
阅读器不上传项目内容，Lectern 没有维护者运营的代码采集或遥测服务。可选 AI CLI 以你的用户权限运行，能够修改文件，并可能按自身设置向模型服务发送代码和对话。模型账号、费用和数据政策由对应服务提供方决定。
