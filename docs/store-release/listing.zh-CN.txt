Lectern 让你直接在 Chrome 中阅读本地项目，理解代码结构、查看改动，并在需要时打开阅读区内的 AI 终端。适合熟悉新项目和审查本机代码，无需先上传文件或启动 IDE。

主要功能

• 本地阅读与语法高亮：选择文件夹浏览目录树，或单独打开文件。支持 29 类语言与语法类型，其中两类采用近似高亮，并在界面明确标注。阅读器只读处理本机文件。

• 代码导航与搜索：通过文件大纲定位内容，按文件名、符号或全文搜索项目。在支持的语言中跳转定义、查找引用，再沿导航历史返回。代码导航基于语法和名称匹配，不保证与语言服务器同等精确。

• 可停靠的 AI 终端：在阅读区右侧或底部使用本机已安装的 Codex 或 Claude Code，沿用自己的登录和模型设置。拖动分隔线调整宽度或高度，布局和尺寸会自动记忆。切换位置或主题时保持当前会话；重连位于工具栏，安装说明和目录关联位于设置。每个项目首次关联本机目录后，后续复用该关联。此功能目前为 macOS 预览版。

• 按后缀自动渲染：从 72 种支持的文件后缀中选择，并开启 Chrome 的“允许访问文件网址”。之后在浏览器打开匹配的 file:// 本地文件，就会在当前标签页进入对应阅读视图。可随时调整或关闭。

• 文档与图片预览：Markdown 可切换富文本和源码视图，支持标题大纲、表格和代码块高亮。打开项目文件夹后，还可查看本地相对路径图片、跟随项目内链接，以及预览常见图片文件。

• 文件与 Git 对比：并排比较两个文件，或基于本机仓库中的分支、标签、提交和工作区查看改动。支持从共同祖先审查差异或直接比较两个版本；Git 视图不会自动拉取远端数据。

界面支持中文和英文、浅色与暗色主题、可调整分栏，以及目录树和代码导航的键盘操作。

终端安装
可选终端要求 macOS 13.5 或更高版本、Google Chrome、单独安装 Lectern Companion，以及已安装并登录的 AI CLI。伴随程序包含运行环境，从 GitHub Releases 下载，目前未签名、未公证；macOS 可能要求用户核对来源后允许安装，受管理的 Mac 可能限制使用。关闭终端会结束当前会话，重新打开会启动新会话。未安装伴随程序仍可使用阅读器。

数据处理
阅读器不上传项目内容，Lectern 没有维护者运营的代码采集或遥测服务。终端中的 CLI 以你的用户权限运行，可以修改文件，并可能向自身配置的模型服务发送代码和对话。相关账号、费用和数据政策由对应服务提供方决定。
