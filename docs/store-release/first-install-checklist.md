# 正式伴随程序安装验收记录

每个承诺支持的架构各填一次。不要把未签名开发包或已预先注册的源码 host 当成正式安装结果。

记录：日期、macOS 版本、芯片、Chrome 版本、扩展来源/ID/版本、安装包文件名/SHA-256、CLI 名称/版本。不要记录密码、令牌或私人项目内容。

- [ ] 干净 macOS 用户没有 Node/npm、源码 host、旧 Lectern Companion。
- [ ] 从不需要维护者登录的公开下载页下载，签名身份正确，系统正常安装，无需绕过 Gatekeeper。
- [ ] 未装 CLI 时有可理解的安装指引。
- [ ] 安装并按官方步骤登录 CLI；不向 Lectern 维护者发送凭据。
- [ ] 从与正式 ID 匹配的扩展打开测试项目，首次系统选择一次同一目录。
- [ ] CLI 能在右侧终端启动、输入和输出；窗口可拖宽，左侧阅读不被遮挡。
- [ ] 关闭后 CLI 退出，重新打开新会话，原项目不用重新选目录。
- [ ] 新项目第一次选目录；同名但不同位置的目录不会混用。
- [ ] 目录移动后能重新关联，异常退出后能恢复。
- [ ] 安装更新保留项目关联；英中文案和系统目录提示符合所选语言。
- [ ] 卸载 companion 后扩展恢复安装指引；CLI 及其账号保持原状。
- [ ] 商店版本公开后再次从商店安装复验，确认新增权限和真实 ID 一致。

本地隔离测试和未签名包通过，不自动勾选以上任何项。
