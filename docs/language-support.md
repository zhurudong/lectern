# 语言与文件类型覆盖清单

> 本清单**逐项对应实现**(`src/lib/filetypes.ts` + `src/preview/languages.ts`),
> 是对外表述(README / 上架文案)的唯一依据。清单与实现不一致视为不通过。
> 核对方式:E2E 对每一档都有断言(见 `scripts/e2e.mjs` 的语言覆盖段落)。

对外表述口径:**说"当前覆盖 X、不覆盖 Y"**,不写"尚未支持""以后补齐"。
不覆盖是**边界**不是欠条 —— 欠条一旦欠着,下次被问起就只能继续欠。

当前共 **28 类语言／语法类型**（JSX / TSX 分别归入 JavaScript / TypeScript），
其中 26 类专用高亮、2 类近似高亮；**9 类支持大纲，对应 23 种文件后缀**。
预览注册表 `previewExtensions()` 共列出 **72 种不同后缀**：45 种代码、2 种 Markdown、
6 种图片、19 种纯文本。整文件名匹配另行处理，不增加后缀总数；二进制占位提示不计为预览。

---

## 能力的两个维度

主 spec 把这两件事分开管,**不要混成一条清单**(它们是正交的:Markdown 是"专用高亮 + 仅大纲"):

| 维度 | 取值 |
|---|---|
| **高亮质量** | 专用高亮 / 近似高亮 / 不覆盖(纯文本) |
| **代码理解** | 可跳转 / 仅大纲 / 不参与 |

预览区用**一枚徽标**表达上述组合,当前会出现四种措辞:

| 预览区标识 | 含义 |
|---|---|
| `可跳转` | 专用高亮 + 文件大纲 + 跳转到定义 + 查找引用 + 全局符号搜索 |
| `仅大纲` | 专用高亮 + 文件大纲,点击条目在文件内定位;不参与定义跳转、引用与全局符号搜索 |
| `仅高亮` | 专用高亮,不参与代码理解 |
| `近似高亮`(虚线边框) | 借相近语言的高亮通道,**准确性不保证**,不参与代码理解 |

> 这四种措辞是**当前实现的展示选择**,不是契约。主 spec 只要求让用户知道
> "高亮是专用还是近似"与"是否参与代码理解",**用几个标签、用什么词由实现决定**。

## 1. 可跳转(7 类语言 / 20 个扩展名)

| 语言 | 扩展名 |
|---|---|
| Python | `.py` `.pyi` |
| Java | `.java` |
| C | `.c` `.h` |
| C++ | `.cpp` `.cc` `.cxx` `.hpp` `.hh` `.hxx` |
| Go | `.go` |
| JavaScript | `.js` `.mjs` `.cjs` / JSX `.jsx` |
| TypeScript | `.ts` `.mts` `.cts` / TSX `.tsx` |

跳转与引用是**基于符号名与语法树的启发式**,不做类型推断、作用域解析、导入解析或宏展开,
**不承诺编译级精确**。C/C++ 的函数原型按"声明"种类单独收录。

## 2. 仅大纲(2 类 / 3 个扩展名)

| 语言 | 扩展名 | 说明 |
|---|---|---|
| Markdown | `.md` `.markdown` | 提供标题层级大纲 |
| SQL | `.sql` | 提供常见对象定义(如表、视图、存储过程)与顶层查询/数据操作(如 `SELECT`、`INSERT`)的大纲 |

点击大纲条目在当前文件内定位;以上两类均**不**参与定义跳转、查找引用与全局符号搜索。
SQL 大纲基于常见语句的启发式识别,不承诺完整的 SQL 方言解析。
语句按分号或常见批次分隔符(`GO`、`DELIMITER`、独占一行的 `/`)划分,CTE 和对象体保持在所属条目内。
普通字符串采用标准 SQL 引号转义,`E'…'` 支持反斜杠转义;依赖 MySQL 会话模式的转义规则不覆盖。
不收录的语法包括 `EXPLAIN`、`TABLE` 简写查询、`CREATE DOMAIN` 等;此处仅举例,非完整清单。不支持带内嵌数据区的 `COPY FROM STDIN` 脚本。

## 3. 仅高亮(17 类)

| 语言 | 扩展名 / 文件名 |
|---|---|
| JSON | `.json` `.jsonc` |
| YAML | `.yaml` `.yml` |
| TOML | `.toml` |
| XML | `.xml` |
| HTML | `.html` `.htm` |
| CSS | `.css` |
| SCSS | `.scss` |
| Sass | `.sass` |
| Less | `.less` |
| Shell | `.sh` `.bash` `.zsh`(以及带 shebang 的无扩展名脚本) |
| Rust | `.rs` |
| Ruby | `.rb` |
| Kotlin | `.kt` `.kts` |
| C# | `.cs` |
| Groovy | `.gradle` `.groovy` |
| Dockerfile | `Dockerfile`(含 `Dockerfile.dev` 等变体) |
| CMake | `CMakeLists.txt` |

CSS 家族(SCSS / Sass / Less)各用**专用**高亮模式,不是拿 CSS 近似顶替。

## 4. 近似高亮(2 类)

| 语言 | 扩展名 | 近似方式与边界 |
|---|---|---|
| Vue | `.vue` | 按 HTML 超集高亮:`<script>` / `<style>` 块正确,**模板指令(`v-if` 等)不保证准确** |
| Svelte | `.svelte` | 同上,`{#if}` 等模板语法不保证准确 |

## 5. 其他处理

| 类型 | 处理 |
|---|---|
| **Makefile** / `makefile` / `GNUmakefile` | **按纯文本展示**。没有可用的专用高亮模式,**不借用 Shell 等模式假装有高亮** —— target、`.PHONY`、变量展开都会被着错色,那是把"缺失"换成"含糊" |
| 纯文本 | `.txt` `.log` `.csv` `.ini` `.cfg` `.conf` `.lock` `.env` `.properties` 等 |
| 图片 | `.png` `.jpg` `.jpeg` `.gif` `.svg` `.webp` —— 原生预览 |
| 二进制 | `.exe` `.zip` `.pdf` `.woff2` `.wasm` 等 —— 提示不渲染 |
| 未知扩展名 | 内容嗅探:二进制则降级提示,否则按纯文本;有 shebang 时按对应脚本语言高亮 |

## 6. 当前**不覆盖**的类型(边界,非欠条)

以下是**常见类型中当前明确不覆盖**的部分,按纯文本(含行号)展示。
**该清单是常见项的举例,并非穷举 —— 未列出 ≠ 已覆盖**:

Swift、Dart、Lua、Scala、R、Perl、PowerShell、Protobuf、PHP、GraphQL、Terraform/HCL,
以及 Makefile(见上表,有意为之)。

判断某个类型是否被覆盖,以第 1–4 节的**覆盖清单**为准:**列在那里的才是覆盖的**,
其余一律按纯文本展示。

> 本清单**逐项对应主 spec** `openspec/specs/file-preview/spec.md`「代码语法高亮渲染」。
> 初稿曾多列了 Objective-C / Haskell / Elixir / Clojure / Erlang / Julia / Zig / Nim ——
> 它们确实也不覆盖,但**不在已批准的清单里**,而这份文档是对外文案的依据:
> 多列等于单方面扩大了对外承诺的边界描述,已删除对齐。

选择依据是**目标用户的实际遇见频率**,不是技术可行性。覆盖范围会随产品定位调整,
但**当前版本的承诺就是上面 1–5 节的内容**。

## 7. 一条贯穿的口径

**宁可明确说不支持,也不提供一个需要向用户解释的近似。**

- CSS 家族有专用模式 → 用专用模式,不用 CSS 顶替。
- Makefile 没有专用模式 → 老实按纯文本,不借 Shell 假装。
- Vue / Svelte 只能近似,但价值足够高(前端仓库占比高)→ 提供近似,**并在界面上明示是近似**。

三种处置不同,判据一致:**用户看到的能力标识必须与实际能力一致。**
