Use your local AI CLI in Lectern

The terminal currently requires macOS 13.5 or later and Google Chrome. The companion bundles its runtime; you do not need to install Node.js separately. The terminal opens beside your code.

First use

  1. __DOWNLOAD__ Choose the installer for your Mac chip and this extension. Open the package and follow the system prompts. Administrator authorization may be required.
  2. Install an AI CLI: Codex or Claude Code. Existing installations and sign-in can be reused. Follow the CLI's own authentication prompts.
  3. Open your project in Lectern, open AI terminal, and click Reconnect. In the system picker, choose the same project folder.

Chrome starts the companion on demand. No port, token or background service is required. The CLI runs with your user permissions: it can read and modify files and contact its configured model providers. Provider accounts, fees and data handling follow that CLI and provider's terms.

Other projects

Previously associated folder: open it and open the terminal. New folder: associate it once. Same-name folders remain separate. Moving a folder or clearing browser data may require association again.

Closing the panel ends the session. Reopening or reconnecting starts a new session; conversation recovery is not guaranteed.

Updates and troubleshooting

Close terminal panels before installing an update from the same download page, then reconnect. If the companion is incompatible or unauthorized, install the package for this extension. Use Change associated folder to correct a folder. For another CLI, enter its absolute executable path in Agent and folder settings.

Uninstall

Close all terminal panels. In Finder, go to /Applications/Lectern Companion.app/Contents/Resources and run Uninstall.command. Confirm system authorization. This removes the companion and Chrome host registration, retaining your CLI installations, sign-in and project associations. Remove the browser extension separately. To erase retained companion associations, remove ~/.lectern-agent/ after uninstalling.
