# Lectern（读码台）

[![CI](https://github.com/zhurudong/lectern/actions/workflows/ci.yml/badge.svg)](https://github.com/zhurudong/lectern/actions/workflows/ci.yml)

**在浏览器标签页里读懂一个陌生代码库 —— 离线、只读，而且这两条你能用一条命令自己验。**

你要读的代码里，越来越多不是你写的：一个马上要信任的依赖、一个被要求审计的仓库、
一个 agent 一夜之间产出的 PR。Lectern 打开本机的一个文件夹，把 IDE 里**读**真正需要
的那部分给你 —— 目录树、语法高亮、文件大纲、跳转到定义、查找引用、全项目搜索 ——
不用装 IDE、不上传任何东西、不连接远程服务。

![Lectern 正在读它自己的源码：左侧目录树、中间只读的语法高亮预览、右侧当前文件的符号大纲](docs/images/hero-light.png)

<sub>图中是 Lectern 在读它自己的仓库。另有暗色主题 —— [同一屏](docs/images/hero-dark.png)。</sub>

## 为什么有它

"我得读一下这份代码"的常见答案是**装个东西**或**传到某处**。而这两条不可用的场合
多到值得为它做个工具：受管控的办公笔记本、客户现场的机器、源码不能出门的审计、
一个不属于你、你也不想粘贴到任何地方的仓库。Lectern 两者都不是 —— 它是一个浏览器
扩展，读取你通过选择器授权的目录，或在开启 Chrome 文件网址权限后读取本地文件地址。

两条性质定义了它，而且**只有成对才成立**：

- **无远程传输**：无遥测、无更新检查、无远程字体、无 CDN、无统计。一切资源都在
  包里；自动打开只使用 `file:///*` 本地文件权限，不申请 HTTP(S) 主机权限。
- **只读**：绝不往你打开的目录里写任何东西 —— 不写锁文件、不写索引缓存、不留标记。
  所有状态都在你自己 Chrome 配置目录下的浏览器存储里。

这两条需要可检查的边界：本地 URL 读取模块单独审计，CI 校验它的精确内容、扩展权限
和 CSP，并检查其余产物中的传输 API 与全部产物中的写入 API。下面的检查命令写在
README 正文，就是为了让你能自己审视这些约束。

### 什么时候不该用它

- **你想改代码** —— Lectern 在结构上就写不了。用编辑器。
- **你需要编译级精确** —— 这里的跳转是启发式的：语法树 + 名字匹配，不做类型推断、
  不做导入解析。要精确答案，用语言服务器。
- **你不在 Chrome 122+ 上** —— Firefox / Safari 的 FSA 支持度不同，不支持。

如果你的问题是**读懂**一份已经躺在你磁盘上的代码，而约束是**什么都不许离开这台
机器**，那正是它被造出来的那个场合。

## 它能做什么

**打开**：通过 File System Access API 选择目录或单个文件，也可将一个目录或文件拖到
查看器页面任意位置打开；最近项目记在 IndexedDB
里（存的是句柄），重启浏览器后一键重连。

**自动打开本地文件**：浏览器打开 `.md`、`.sql`、`.java` 等已选后缀的 `file://` 文件时，
在当前标签页进入 Lectern。顶部「自动打开」可配置总开关与后缀；首次需开启 Chrome
的文件网址访问权限。进入的是单文件模式，不会获得父目录句柄。

**浏览**：惰性加载 + 虚拟滚动的目录树，约 10,000 文件规模下依然顺手；目录优先、
名称自然排序。那些"你不是来读它"的重目录 —— `.git`、`node_modules`、`target`、
`.venv`、`__pycache__`、`dist`、`build`、`.next`、`.cache` —— 是**被折叠，不是被吞掉**：
每一层会显示一行「已隐藏 N 项」，点开就能照常浏览、下钻。

![项目根目录：被排除的目录收成一行斜体的「已隐藏 3 项」，排在普通文件下方](docs/images/tree-hidden-light.png)
里面的文件仍可预览、仍有
大纲；它们不进项目级搜索与跳转，**而且预览区会直接说明这条边界** —— 不用你从"搜了
没结果"里去猜。

目录树**可以完全用键盘走完**，键位遵循 WAI-ARIA `tree` 的既定约定：上下移动、右展开
/ 进子项、左折叠 / 回父级、`Enter` 打开、`Home`/`End` 到首末行。**光标所在的行与正在
预览的文件在视觉上是分开的** —— 因为它们不总是同一行。

**阅读**：CodeMirror 6 只读渲染，行号 + 语法高亮，浅色/暗色双主题，可拖拽的分栏
分隔条，可折叠的大纲栏。Markdown 富文本渲染（GFM 表格、代码块按声明语言高亮）与
源码视图一键切换；相对路径图片经目录句柄本地解析；项目内相对链接点击即在查看器里
打开；HTML 经 DOMPurify 净化；**远程图片一律不加载**。

**对比本地 Git 快照**：项目里的「变更」视图可选本地分支、远程跟踪分支、Tag、完整或
唯一前缀的 Commit SHA；当前工作区可作为目标。远程跟踪分支只是 `.git` 里已有的引用，
界面永久标注「本地快照」，Lectern 不会 fetch。「审查改动」比较 merge base 到目标，
「直接比较」比较两个所选端点。变更文件按新增 / 修改 / 删除分组，以只读 unified diff
和事实元数据展示。

**读懂**（离线，无语言服务器，索引不落盘）：

- **文件大纲**：当前文件的类型 / 函数 / 方法 / 字段 / 常量，点击定位到行。
- **跳转到定义**：`⌘/Ctrl` + 点击，或右键菜单，跨文件定位。**同名多处定义时给
  候选列表让你选，不替你猜。**
- **查找引用**：按文件分组列出；注释与字符串字面量里的同名文本靠语法树排除，不是
  正则猜。
- **符号搜索**与**全文搜索**：后者结果流式回填、按文件分组、随时可停。
- **导航栈**：逐级回到跳出前的文件与行。
- **能力标识**：预览区标出当前文件属于哪一档能力 —— 不用靠"点了没反应"来猜。

代码理解是**启发式**的：语法树抽取 + 符号名匹配，不做类型推断、作用域解析、导入
解析、宏展开，**不承诺编译级精确**。

## 语言覆盖

当前覆盖 **29 类语言／语法类型**：27 类专用高亮、2 类近似高亮。
JSX 归入 JavaScript，TSX 归入 TypeScript。

| 档位 | 类数 | 语言 |
| --- | --- | --- |
| **可跳转**（高亮 + 大纲 + 跳转 + 引用 + 符号搜索） | 9 | Python、Java、C、C++、Go、JavaScript（含 JSX）、TypeScript（含 TSX）、Rust、PHP |
| **仅大纲** | 2 | Markdown（标题层级）、SQL（常见对象定义与顶层查询/数据操作） |
| **仅高亮** | 16 | JSON、YAML、TOML、XML、HTML、CSS、SCSS、Sass、Less、Shell、Ruby、Kotlin、C#、Groovy、Dockerfile、CMake |
| **近似高亮**（界面上明示） | 2 | Vue、Svelte |

**文件大纲覆盖 11 类语言／格式，共 29 种文件后缀**：上表的 9 类可跳转语言
（26 种后缀），加上 Markdown（`.md`、`.markdown`）和 SQL（`.sql`）。
代码大纲展示类型、函数、方法等符号，Markdown 大纲展示标题层级；点击条目即可定位到行。

**Rust（`.rs`）与 PHP 支持专用高亮、大纲、定义跳转、查找引用和全项目符号搜索**，与上表的可跳转档一致。

按文件后缀统计，预览注册表共包含 **72 种后缀**：45 种代码、2 种 Markdown、
6 种图片（`.png`、`.jpg`、`.jpeg`、`.gif`、`.svg`、`.webp`）、19 种纯文本。
`Dockerfile`、`CMakeLists.txt`、`Makefile` 等按完整文件名识别，另行处理，不计入后缀总数。
二进制文件的占位提示不计为可预览。

SQL 大纲启发式识别常见语句，包括表、视图、存储过程等对象定义和顶层
`SELECT` / `INSERT` 等语句；点击条目在当前文件内定位。SQL 不参与定义跳转、
查找引用或全项目符号搜索，大纲不提供完整的 SQL 方言解析。

其他源码与配置类型（包括 Makefile）按纯文本（含行号）展示。常见类型中当前明确**不覆盖**
的有：Swift、Dart、Lua、Scala、R、Perl、PowerShell、Protobuf、PHP、GraphQL、
Terraform/HCL —— **该清单是举例，并非穷举，未列出 ≠ 已覆盖**。判断依据是上表的
覆盖清单：**列在里面的才是覆盖的**。逐扩展名的完整清单见
[`docs/language-support.md`](docs/language-support.md)。

## 安装

需要 **Chrome 122+**。

**推荐：**[从 Chrome 应用商店安装 Lectern](https://chromewebstore.google.com/detail/lectern/ahmcjpgaejjfgiihipkjlhmepcnkbddm)。
后续更新由商店完成，不需要开启开发者模式。

如果要审计安装包，或固定使用某个 GitHub Release，可手动安装：

1. 到 [Releases](../../releases) 下载 `lectern-<版本>.zip`。
2. 解压，**把解压出来的 `lectern` 文件夹放到一个固定位置**。Chrome 每次启动都从这个
   文件夹加载扩展 —— **移动或删除它，扩展就失效了**。
3. 打开 `chrome://extensions`。
4. 打开右上角的**开发者模式**开关。
5. 点左上角**「加载已解压的扩展程序」**，选第 2 步那个 `lectern` 文件夹。
6. 点工具栏的拼图图标，把 Lectern 固定出来，然后点它的图标打开查看器。

手动安装时有三件事容易让人以为出了问题，其实都不是：

- **每次启动 Chrome 都提示"停用开发者模式扩展"** —— 手动加载的扩展就是这个样子，
  点关闭即可。
- **重连最近项目时可能再次请求授权** —— 在那个弹窗里选**「每次访问时允许」**，之后
  就不再问了。
- **有些目录根本选不了**（系统目录、下载目录根等）—— Chrome 不允许把它们交给任何
  扩展，请选它的子目录。

**也可以自己构建**，如果你不愿意跑一个不是自己产出的产物：

```bash
npm ci
npm run build     # 产物在 dist/ —— 第 5 步改选这个目录
```

每个 GitHub Release 都从同一个 tag 的构建中产出两份明文归档：

- `lectern-<版本>.zip` 外包一层 `lectern/` 目录，方便手动解压安装；
- `lectern-<版本>-web-store.zip` 的 `manifest.json` 位于包根，**这一个文件会原样上传到
  Chrome 应用商店**。

两份归档旁边都有 SHA-256。商店会为上传包签名并重新封装成 CRX，同时加入商店元数据，
所以下载到的 CRX 与上传 zip 不会逐字节相同；其中的扩展载荷仍必须与 tag 构建一致。

## 上手

1. **打开文件夹** —— 在欢迎页点「打开文件夹」选一个项目目录（「打开文件」则是看
   单个文件）。最近项目就列在那一页，重启浏览器后一键重连。
2. **读** —— 在左侧点一个文件。右侧「大纲」是当前文件的结构，点条目直接定位到那行。
3. **对比 Git 快照** —— 从「文件」切到「变更」，选择基准、目标和「审查改动」/
   「直接比较」。锚点面板按当前工作区、本地分支、远程跟踪分支（本地快照）、Tag 和
   Commit SHA 分组；`⌥↑` / `⌥↓` 在差异片段间移动。
4. **跳转到定义** —— **按住 `⌘`（macOS）或 `Ctrl`**，可跳转的标识符会显示下划线，
   点一下就过去了。右键菜单里有同样的入口，另有**「查找引用」**，按文件分组列出。

   ![按住修饰键后，可以跳转的标识符显示下划线](docs/images/jump-affordance.png)

   <sub>图中是一个两文件的小样本，好让下划线看得清楚。你不必靠"点了才知道"来猜某个
   符号能不能跳 —— 按住键，能跳的会自己说出来。</sub>
5. **回来** —— 预览区左上角的前进/后退箭头，逐级回到你跳出去之前的那一行。
6. **三种搜索** —— 顶部搜索框可切换「文件名」（`⌘K` / `Ctrl+K`）、「符号」（跨项目
   找定义）、「全文」（边扫边出结果，可随时停），三者互不干扰。
7. **用键盘** —— `Tab` / `Shift+Tab` 在目录树 / 代码区 / 大纲之间切焦点；树里 `↑↓`
   移动、`→`/`←` 展开折叠、`Enter` 打开文件；代码区方向键移光标、**`⌘↩` 跳转到定义**、
   **`⌘⇧↩` 查找引用**、`⌥←` 后退；大纲里方向键 + `Enter` 定位。

   顶栏的 **`?`** 按钮列出全部键位，`Esc` 关闭 —— 而这一条**面板自己第二行就写着**：

   ![键盘操作面板：按面板分组列出切焦点、目录树、代码区、大纲与搜索的键位](docs/images/keyboard-help.png)

   <sub>面板上的键位标注与实际绑定**取自同一处**，所以改了绑定不可能留下一个过期的
   标注 —— 有一个变异测试专门改绑定，两处不同步就失败。面板最后一行是边界：**没列出
   的组合就是在当前平台没有绑定**，因为它们在那个平台上没有经过真机核验。</sub>
8. **外部改了文件要刷新** —— 目录树上方的 ↻ 重读目录结构；重新点击文件总是从磁盘
   重读。自动打开的本地文件则刷新浏览器标签页重新读取。**没有自动监听**，因为这个
   API 不提供变更事件。

macOS 上另有两个经真机核验的快捷键：`⌘⇧O` 符号搜索、`⌘⇧F` 全文搜索。Windows / Linux
上**有意不绑定**这类键位，原因见[边界](#边界)。

### 自动打开本地文件

1. 点击查看器顶栏的「自动打开」，从设置中的入口进入 Chrome 扩展详情，开启
   **「允许访问文件网址」**。也可从 `chrome://extensions` → Lectern →「详情」找到
   这个开关。通过原有「打开文件夹」或「打开文件」选择器阅读，不需要开启它。
2. 勾选要接管的后缀并保存。总开关初始开启，默认选择代码、Markdown 和纯文本后缀，
   HTML 与图片默认不选。支持全选、清空、恢复默认与关闭总开关；保存后用于之后的导航。
3. 在 Chrome 中打开匹配的本地文件，当前标签页会直接进入 Lectern。外部修改文件后，
   刷新这个标签页即可重新读盘。

匹配不区分大小写，支持 URL 编码、空格和中文文件名。候选与预览支持格式同源，不纳入
不支持预览的二进制。**这里只匹配后缀**：`Dockerfile` 等无后缀文件仍可手动打开，但不
属于自动打开规则。不接管 HTTP(S) 地址、目录、子框架或网页子资源，也不改变系统默认
打开方式。

权限未开启或被撤销、文件不存在、读取失败时，查看器会显示原因与恢复入口。自动 URL
读取上限为 **64 MiB**，更大文件可改用「打开文件」手动选择；文本预览仍遵循原有规则：
超过 **5 MiB** 只显示前 **1 MiB**，并标明截断。

单文件模式保留大纲和适用的文件内跳转。跨文件跳转、查找引用、项目搜索，以及 Markdown
相对图片和链接仍需打开所在文件夹；自动打开不会顺带授予父目录访问能力。

## 自己验证那两条承诺

```bash
npm ci && npm run build
node scripts/check-invariants.mjs
```

**请先读脚本再信检查。** 它按精确白名单检查产物的权限与 CSP，禁止全部产物出现文件
写入 API，并禁止唯一审计模块 `local-file-reader.js` 之外出现传输 API。该模块使用固定
摘要校验，任何内容变化都需要重新审计并更新校验；负向检查覆盖 HTTP(S)、远程文件主机
与无效地址。禁用符号清单由脚本唯一维护。

标准构建仅声明 `storage` 与 `declarativeNetRequestWithHostAccess`，主机权限只有
`file:///*`；仅将 `viewer.html` 对 `file:///*` 暴露为可访问资源。CSP 为
`script-src 'self'; object-src 'self'; connect-src 'self' file:`。选择器来源仍经
`handle.getFile()` 读取；本地 URL 模块验证地址、禁止重定向并限制读取大小。渲染内容
不得成为任意读取本地文件的入口。

同一个脚本在每次 push 与 PR 的 [CI](.github/workflows/ci.yml) 里跑，破坏任一条即
构建失败。在浏览器里也可检查 DevTools → Network：扩展资源和本地 `file://` 读取是
正常行为，不应出现外发 HTTP(S) 请求。

## 边界

以下是**边界，不是欠条** —— 不要理解成"以后会补"。

- **仅 UTF-8 解码**：GBK / Latin-1 等编码会显示乱码，不做编码检测。
- **无文件变更通知**：File System Access API 不提供变更事件，外部改动后需手动刷新
  目录树或重新点击文件；自动打开的本地文件需刷新浏览器标签页。
- **只读**：不提供编辑与保存。
- **Git 对比仍然只读且只看本地**：不做 fetch / pull / checkout，不读写 index，不提供
  stage / commit / merge，也不写任何 Git 文件；远程跟踪分支只是本地快照，不代表远端
  当前状态。
- **Git 仓库形态有明确边界**：支持对象库位于授权根内的 SHA-1、非 bare 仓库；bare、
  SHA-256 object format、授权根外的 gitdir / alternates 会给出具体不支持原因。浏览器无法
  精确观察工作区 executable bit 与 symlink，界面会披露，不会把受限结果说成完整结果。
- **受保护目录无法选择**：Chrome 不允许授予某些目录（系统目录、下载目录根等），
  请选它的子目录。
- **索引只在内存**：重开项目会重建（约 10,000 文件为秒级）；超过 5 MiB 的单文件不
  参与符号抽取；符号总数上限 400,000 条，达上限会明示"仅部分完成"而不假装完整。
- **大文件截断**：超过 5 MiB 的文本只显示前 1 MiB，并明示已截断。自动 URL 读取上限
  为 64 MiB，更大文件可手动选择，文本预览仍有相同截断规则。
- **仅 Chrome**（及同内核浏览器）：Firefox / Safari 的 FSA 支持度不同。
- **Windows / Linux 的补充快捷键有意不绑定**：候选键位在这些平台与浏览器级快捷键
  冲突且无法真机核验，因此**不绑定、也不在界面上提示** —— 全部能力都能从界面入口
  完整使用。仅 macOS 绑定并提示经真机核验的键位。
